With a hosted code-execution tool available (OpenAI configurations only), mini's raw-input future-joint accuracy rises by +54.2 [+45.3, +62.5] points on synthetic histories and +77.1 [+68.8, +84.4] on profiles, and GPT-5.4 reaches 100\% on raw input in both cohorts; mini ran code in 469 of 576 calls and was exact in 453 of them, versus 93 of the 107 calls it answered without code. Against the interface-matched automatic-choice baseline the tool's own contribution on synthetic histories is +34.9 [+26.0, +43.8] points on raw and +11.5 [+6.2, +17.7] on canonical input. Letting the model delegate selection and rollout to code it writes is the most effective single placement at fixed input, though not error-free (Appendix~\ref{app:extensions}).
